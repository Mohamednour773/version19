How It Works

1

Enable per POS

Go to POS Configuration > Inventory tab > Stock Control section. Toggle “Prevent Negative Stock” on.

2

Cashier scans a product

The module instantly checks available quantity in the linked warehouse. If stock would go negative, a popup blocks the action.

3

Manager override (optional)

If enabled, the popup offers a Manager Override button. The manager enters their PIN and optionally a reason.

4

Server validates on sync

When the order syncs to the backend, the server re-validates stock. Unauthorized overrides are rejected with a clear error.

Frequently Asked Questions

Does it work offline?

Yes. When offline, the POS uses the last loaded stock snapshot. An optional safety buffer percentage can be configured. The server re-validates when the order syncs.

Does it affect refund/return orders?

No. Return lines (negative qty) are never blocked, since they increase stock. No false positives on returns.

Can I exclude service products?

By default, only storable products are checked. You can also exclude specific products or entire categories via the configuration.

Is it multi-company safe?

Yes. Stock checks are scoped to the POS warehouse. Override audit logs are company-isolated via record rules.
